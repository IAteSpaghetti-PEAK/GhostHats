# GhostHats

Be able to see player's hats on their ghosts.

That's it. That's the whole mod.

## Install

Install it with a mod manager, or drop `GhostHats.dll` into `BepInEx/plugins/`.

Needs the PEAK BepInEx pack, which the mod manager pulls in for you.

## Simple Info

**Only you need it.** The mod is entirely client-side so it works
in any lobby, public or private, and nobody else has to install anything. Hats show up on every
ghost you can see.

Hats only appear for you and other people with the mod.
